PERFORMANCE / STRENGTH & BOXING

Training Lab

Evidence-informed strength, muscle growth and boxing-specific power, with a local workout log and a Cus D’Amato-style Willie Bag number caller.

Programming principles

Build strength, size and punch-specific power without junk volume

Use this as a starting template, not a claim that one routine is universally optimal. Keep boxing skill work the priority when technical quality or recovery is slipping.

  • Strength: usually 3–5 reps on primary lifts, challenging loads, full controlled range of motion and 2–4 minutes rest.
  • Hypertrophy: for muscles you want to prioritise, work gradually toward roughly 10 hard sets per week; use mostly 6–15 reps and add volume only while recovering. The example plan starts more conservatively to leave room for boxing.
  • Effort: finish most sets with about 1–3 good reps in reserve. Training to failure is not required.
  • Boxing power: do jumps and medicine-ball throws fresh, with low reps and full intent; stop when speed or technique drops.
  • Progression: when every set reaches the top of its rep range with stable technique and the planned effort, add a small amount of load next time.
Evidence summary: a 2026 ACSM overview of 137 systematic reviews found heavier loads (around ≥80% 1RM) particularly useful for maximal strength, higher weekly volume (around ≥10 sets per muscle) helpful for hypertrophy, and moderate loads moved fast useful for power. Boxing evidence links punch impact to lower-body maximal and explosive strength, but boxing-specific study quality remains limited.
Session A · Strength

Lower + upper strength

  • Squat or trap-bar deadlift — 3×3–5
  • Bench press or push-up variation — 3×4–6
  • Weighted chin-up or row — 3×5–8
  • Romanian deadlift — 2–3×6–8
  • Anti-rotation core (Pallof press) — 2–3×8–12/side

Rest: 2–4 min on main lifts. Keep 1–3 reps in reserve; use a spotter/safeties for heavy barbell work.

Session B · Power + strength

Explosive intent

  • Countermovement jump — 3×3
  • Medicine-ball rotational throw — 4×3/side
  • Front squat or split squat — 3×5–8
  • Overhead press — 3×5–8
  • Pull-up or chest-supported row — 3×6–10
  • Calf raise or hamstring curl — 2×10–15

Perform jumps/throws first. Reset between reps; these are power drills, not conditioning finishers. Use a safe clear area and suitable medicine ball.

Session C · Hypertrophy

Full-body muscle growth

  • Leg press or squat — 3×6–10
  • Incline dumbbell press — 3×6–12
  • Seated row — 3×8–12
  • Hip hinge or hamstring curl — 3×8–12
  • Lateral raise — 2–3×12–20
  • Biceps curl + triceps cable pressdown — 2×10–15 each

Use controlled reps and a comfortable range of motion. Add sets only if performance, joints and boxing sessions are recovering well.

Session D · Boxing specificity

Willie Bag + conditioning

  • Warm-up and shadowbox — 5–8 min
  • Willie Bag number calls — 4–6×2–3 min, 60–90 sec rest
  • Footwork/defence after each combination — keep guard and balance
  • Optional easy aerobic work — 15–25 min, if it does not compromise recovery

Start with short 2–3-number sequences and controlled accuracy; progress toward longer calls only when technique stays clean. Bag work complements coaching and sparring; it does not replace them.

How to arrange the week

Start with 2–3 resistance sessions weekly, separated where possible from the hardest boxing sessions. A simple sequence is A / rest or boxing / B / rest / C / boxing skill / rest. If boxing performance is the top priority, put technical boxing first on double-session days and reduce lifting volume during hard sparring weeks. Leave at least one genuine recovery opportunity each week.

Safety: warm up, learn lifts with a qualified coach, and stop for sharp pain, dizziness or unusual symptoms. Do not test maximal lifts alone. If you are new to lifting, start lighter and build technique before loading aggressively.

How to run the drill

  1. Start with 2–3-number calls at a comfortable pace.
  2. Strike the called zone with clean mechanics, return to guard, and keep your feet balanced.
  3. Build speed only when the target, punch choice and defence stay correct.
  4. Use the Stop button between rounds; do not chase fatigue with sloppy or painful punches.
